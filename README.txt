BLOOM-THE-RIZZ website package

Files:
- index.html: website structure and SEO metadata
- style.css: extracted styling
- script.js: extracted website interactions and product data
- assets/: images that were embedded as base64 in the original HTML

Upload the contents of this folder to the ROOT of your GitHub Pages/Cloudflare Pages repository.
Keep the assets folder and its filenames unchanged.
The index.html references style.css, script.js, and assets/ paths relatively.

Note: The original page used embedded base64 images. They have been saved into assets/ and the references updated.
